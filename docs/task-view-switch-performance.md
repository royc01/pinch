# 大量任务下的视图切换

此次优化减少已加载数据下的重复计算和页面节点，尤其是 6000 个以上任务时的来回切换和滚动。针对桌面客户端首次加载日历、月周切换仍然卡顿的反馈，日历改为共用一个侧栏实例，并减少关闭记录图层时的数据读取和滚轮触发的重复渲染。

## 改动

- 筛选缓存按任务集合独立保存 Vue computed，不再为了命中缓存拼接全部任务的标题、归档状态。标题检查由各筛选结果共享；状态、优先级、路径、归档和任务集合变化会自动更新结果。
- 看板、列表、四象限分别保留筛选结果，使用各自的文档范围，避免切换其他视图时让隐藏视图的筛选失效。
- 看板、列表的卡片高度索引按任务数组缓存。滚动和重复渲染复用索引；展开、测量高度、调整顺序、增删任务后重新计算。
- 表格和甘特图使用最多两个实例的 KeepAlive 缓存。切换时保留组件和派生数据；隐藏后关闭弹窗、解除交互监听、停止布局测量和甘特图时钟，恢复时重新绑定。
- 甘特图补全子任务树时允许复用完整数据缓存，日期回写仅监听等待确认的日期字段，避免深度监听所有任务。
- 表格默认排序每次排序只计算一次当天起点。
- 日历侧栏保留笔记本、文档分组的完整高度，只挂载滚动窗口附近的任务按钮。搜索、分组折叠、显示已完成任务、勾选、编辑和指针拖动继续使用完整任务集合。
- 月、周、日和三日视图通过 CalendarViewShell 共用同一个侧栏。首次显示时挂载，切换模式、折叠侧栏或离开日历后保留实例及搜索、折叠、滚动状态；任务筛选不依赖当前日历模式。迷你日历选日期、编辑和拖动路由到当前视图。
- 超过 500 个侧栏任务时，用宏任务分批准备标题缓存，每批预算 4 毫秒；隐藏或卸载时取消待执行工作。普通文本标题直接规范空白，含 HTML、Markdown 或实体的标题保留原解析路径。
- 月视图展开后仍保留完整周行高度，只渲染视口附近的大任务区卡片。周、日和三日视图在全天任务超过 100 行时限制区域高度，使用区域内滚动查看全部任务，卡片按滚动位置渲染。
- 月、周视图的重叠排布用两个最小堆保留原有的最小可用行顺序，计算从最坏 O(n²) 降为 O(n log n)。不再按整段日期逐日扫描每一条已占用的行。
- 时间任务的重叠排布也改用最小堆，保留最低可用列与端点相接时复用列的行为。月视图每周的可见任务和折叠计数只计算一次，日期格读取缓存结果。
- 日历任务同步和任务日志发布只观察所用字段，避免递归监听整个子任务树。任务原地修改仍会同步；日历筛选固定使用所属视图的范围，保留切回时已经浏览的日期窗口。
- 所有视图共享最多 10000 个标题的纯文本解析缓存，避免 6000 多个标题在原有的小缓存中反复淘汰、重新创建 DOM 来解析 HTML。
- 日历、表格和四象限的尺寸测量按帧合并，先读取所有排队的几何信息，再更新响应式布局。表格虚拟范围计算不再在渲染期间读取 clientHeight；隐藏视图会取消待执行的测量。
- 月视图滚轮监听只绑定日历网格并使用 passive。有垂直溢出时使用原生滚动；短网格保留每次移动七天的导航，以 200 毫秒节流。侧栏输入、横向滚动和缩放不会触发该导航。
- 任务记录图层关闭时跳过额外的任务日志读取；习惯、专注、其他记录关闭时跳过初次读取及无关更新事件。显式打开日期日志面板后按需读取相关数据。隐藏的日历忽略全局任务拖动和删除快捷键；周视图隐藏时停止时钟，恢复时只启动一个时钟。

## 验证

6501 个任务的回归用例验证：

- active/archived 筛选来回切换 20 次，标题检查总共仍为 6501 次，返回同一个已缓存结果。
- 高度索引连续读取 40 次，卡片高度计算总共仍为 6501 次。
- 表格渲染行数小于 100，切回后复用组件；隐藏期间替换任务数据，恢复后显示最新集合。
- 甘特图切回后复用组件和子任务树，隐藏期间停止时钟，恢复后启动一个时钟。
- 缓存结果能正确响应原地修改、同数量数据替换和文档路径变化，不会跨任务集合串用。
- 日历侧栏挂载的任务按钮少于 80 个，能滚动到第 6501 个任务，并保持搜索、折叠、勾选、编辑及滚动期间的指针拖动行为。
- 月周切换时侧栏组件实例不变，6501 个侧栏标题不会再次全量处理；折叠、离开和返回日历后仍保留搜索。共享布局只有一份外层间距，迷你日历选择会更新当前周日期。
- 6501 个任务全部安排在同一天时，月、周视图挂载的任务卡片均少于 100 个；滚动到末尾能显示最后一个任务。
- 月、周视图能响应原地修改的标题、状态和日期，不读取无关嵌套字段。
- 重叠排布与旧算法在随机跨日区间中结果一致；6501 个完全重叠任务各自占用一行，端点同日的任务仍不会共用一行。
- 时间任务重叠排布与旧算法在随机区间中结果一致；6501 个同时间任务各自占用一列。
- 6501 个不同标题在首次解析后再次读取，不再创建用于解析的 DOM 元素。
- 布局测量去重、读写顺序及隐藏/卸载时的取消行为通过回归验证。
- 滚轮不会阻止默认滚动；溢出的月网格不会更改日期，短网格的连续输入不会反复导航。关闭记录图层时无初次数据读取，打开日期面板后正常加载。侧栏隐藏后取消排队的标题准备，恢复时显示最新集合；缓存周视图的时钟随激活状态停止和恢复。

完整回归：110 个测试文件、710 项测试通过；TypeScript 类型检查、前端和内核生产构建通过。构建输出位于工作区 `dist` 目录。

这些用例验证计算量和行为，并非思源中的帧率或整次切换耗时。首次加载、新筛选条件、数据变化后的全量计算仍与任务数量有关；是否达到几十个任务时的实际响应速度，还取决于数据结构、分组数量及运行设备。
